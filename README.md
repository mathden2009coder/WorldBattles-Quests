# WorldBattles Quests — Forge 1.20.1

Version 0.1.13 fixes the NPC texture resource pack and removes text drop shadows from the quest screen.

- Maylline's original 1024x1024 Blockbench texture is kept at full resolution. Her geo UV canvas remains 256x256 as authored in Blockbench.
- Dr. K. Driver's 512x512 texture is included in the generated resources. His geo UV canvas remains 128x128.
- Texture and model files are packaged together by the Gradle extractMayllineAssets task.
- All quest GUI text is drawn without the default Minecraft drop shadow.
- Forge 1.20.1-47.4.10 / Java 17 / GeckoLib 4.4.9.

Build output: WorldBattlesQuests-0.1.13.jar.
