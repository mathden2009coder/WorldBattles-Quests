# WorldBattles Quests — Forge 1.20.1

Projet Forge 1.20.1 / Forge 47.4.10 / Java 17 / GeckoLib 4.4.9.

La version 0.1.13 conserve Jarvis, le Traqueur et Maylline, leur lore, leurs quêtes et les progressions sauvegardées. Le rendu de l'interface est sans ombre portée pour garder le texte lisible sur le parchemin de Maylline.

Le build ajuste automatiquement les atlas UV de Maylline (1024 × 1024) et du Traqueur (512 × 512) pour correspondre aux textures en haute résolution. La texture `hunter.png` est contrôlée pendant la compilation afin d'éviter sa disparition silencieuse.

Les récompenses, quantités et sauvegardes de progression restent inchangées.
